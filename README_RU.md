# Orbit Launcher — Android

Минималистичный Android-лаунчер на Kotlin. Проект предназначен для импорта в Android Studio или CodeAssist.

## Возможности
- Замена домашнего экрана Android (после выбора Orbit в системном диалоге Home).
- Поиск установленных приложений.
- Сетка с 3–6 колонками.
- Маленькие, средние и большие иконки.
- Переключатель подписей.
- Тёмная и светлая темы.
- Избранное: удерживай иконку приложения.
- Фильтр избранного кнопкой ★.
- Сортировка по алфавиту или избранное сверху.
- Сохранение настроек и избранного.
- Кнопка обновления списка приложений.

## Импорт в CodeAssist
1. Распакуй ZIP в папку на телефоне.
2. В CodeAssist выбери открытие/импорт существующего Android-проекта и укажи папку `OrbitLauncher`.
3. Дождись синхронизации Gradle. Если спросит установить Android SDK Platform 35, установи доступную совместимую платформу.
4. Собери APK через меню сборки проекта.
5. Установи APK и открой Orbit Launcher.
6. Чтобы сделать его домашним экраном: Android **Настройки → Приложения → Приложения по умолчанию → Приложение главного экрана** и выбери **Orbit Launcher**. Названия пунктов могут различаться у производителя.

## Важные ограничения
- Лаунчер не устанавливает приложения за тебя. Он показывает приложения, уже установленные на устройстве.
- Это первая версия: нет виджетов Android на рабочем столе, жестов, резервного копирования и отдельного редактора раскладки.
- На некоторых версиях Android доступ к списку приложений может быть ограничен системой.
- Для сборки нужен Android SDK и совместимый Gradle/Android plugin. В этой среде нет установленного Android SDK/Gradle, поэтому здесь создан проект, а не готовый APK.

## Данные и разрешения
- Приложение использует список запускаемых приложений, локальные настройки и список избранного.
- Сетевые разрешения не запрашиваются.
- `QUERY_ALL_PACKAGES` нужен для отображения установленных приложений и может вызвать предупреждение при публикации в Google Play.
